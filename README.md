# 三梅杀录像导出工具

用于将《三梅杀》录像导出为视频的伴侣工具，支持 Windows / macOS。

> [!WARNING]
> 本工具在 macOS 上的支持度一般，频现掉帧；仅供小范围测试，不适合用于正式用途。

## 使用方式

### 安装

#### Windows

1. 在 [Releases](https://github.com/xianying-studio/SanmeiKill-RecordExporter/releases/latest) 下载 `Setup.0.1.0.exe` 后双击，接着跟随向导完成安装；
2. 通过安装向导结束画面的「运行“三梅杀录像导出工具”」复选框打开应用或者手动打开应用，直到出现 `请通过三梅杀的「导出录像」功能唤起本应用使用。` 后即可点击 `确定` 关闭，安装完成。

#### macOS 测试版

1. 在 [Releases](https://github.com/xianying-studio/SanmeiKill-RecordExporter/releases/latest) 下载 `-0.1.0-arm64.dmg` 后，将 `三梅杀录像导出工具` 拖放到右边的 `Applications` 文件夹；
2. 打开终端，输入 `sudo xattr -r -d com.apple.quarantine /Applications/三梅杀录像导出工具.app` 并回车来信任此应用 (以免出现「已损坏」提示)，若仍提示不受信任，请打开 系统设置 > 隐私与安全性 > 仍要打开 完成应用信任；
3. 打开应用，直到出现 `请通过三梅杀的「导出录像」功能唤起本应用使用。` 后即可点击 `确定` 关闭，安装完成。

### 使用

1. 在《三梅杀》内点击 其他 > 录像；
2. 选中希望导出的录像，选择「存」；
3. 在「导出为...」对话框选择「视频 (通用)」；
4. 若出现「三梅杀 想要访问访问此设备上的其他应用和服务」，请选择「允许」；
5. 若出现「三梅杀 想要打开 三梅杀录像导出工具：将《三梅杀》录像文件导出为视频」，请选择「打开」；
6. 在弹出的「导出录像视频」对话框中，选择希望存储录像视频的导出位置；
7. 保持「三梅杀」与电脑处于开启状态，等待导出完成。

## 渲染路径

Windows 和 macOS 默认使用 Electron 43.8.4 的 GPU 共享纹理，将离屏画面作为 `VideoFrame` 交给 WebCodecs 编码，避免逐帧读取并复制 BGRA 位图。纹理和编码队列均有引用管理与背压限制；GPU 无法提供共享纹理时会重新使用位图兼容路径。

排查驱动兼容问题时，可设置 `EXPORTER_FRAME_TRANSPORT=bitmap` 强制使用位图模式。共享纹理优化的是采集与传输开销，不改变成片播放速度，也不保证硬件编码器一定可用。

## 本地包体传输

配合新版三梅杀，工具会请求浏览器直接将当前缓存导出为 `.smk` 数据流。每个传输块最多 1 MiB，收到工具写盘确认后才发送下一块；不需要额外保存或选择包体文件。

工具校验元数据和全部资源的 SHA-256 后，直接按索引读取临时 `.smk`，为离屏页面提供同源资源、版本信息和音频 Range 请求。此模式禁止页面回源下载，包体缺失或损坏时会明确失败；取消或结束后清理临时文件。旧网页端未提供流接口时继续使用原有联网加载方式，旧工具也能继续接收新版网页端的录像消息。
